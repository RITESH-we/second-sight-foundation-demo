## 📸 Key Features at a Glance

- 🌙 **High-Contrast Dark & Light Mode**: Seamless one-click switch between rich daylight minimalism and deep mystical obsidian night mode with tailored high-contrast visibility.
- 🎯 **Interactive Healing Matcher**: Visitors select their primary health priority (*Digestion, Heart Health, Energy, Blood Sugar, Joint Comfort, Focus, Liver Detox, Aura Clearing*) to instantly discover and open the matching formula.
- 💱 **Live Multi-Currency Engine**: Dynamic real-time conversions across **INR (₹)**, **USD ($)**, **EUR (€)**, and **GBP (£)** across all cards, modals, and the cart.
- 🛍️ **Slide-Out Reactive Cart Drawer**: Features an animated free shipping progress bar (orders ₹999+), quantity steppers, item removal, and promotional code engine.
- 🎟️ **One-Click 50% Off Coupon**: Copyable promo banner featuring code **`SPIRIT50`** that auto-fills into the checkout flow.
- ⚡ **1-Click "Buy Now" Instant Checkout**: Skip the cart drawer and jump straight to the Express Checkout modal.
- 👥 **Live Social Proof Popups**: Subtle notifications showcasing verified purchases across India in real-time (*e.g., "Rohan V. from Pune purchased Digest Harmony Tea 2 mins ago"*).
- ⏱️ **Flash Sale Digital Countdown**: Ticking digital countdown clock creating authentic purchase urgency.
- ❤️ **Interactive Wishlist**: Save favorite remedies with heart animations and persistent local storage.
- 👁️ **Deep Product Quick-View Modals**: Detailed breakdowns including therapeutic benefits, natural botanical ingredients, and recommended usage directions.
- 💬 **Direct Consultation Channels**: Dedicated floating WhatsApp advisor and structured inquiry contact forms.

## 🛠️ Elimination of Flaws from the Legacy Website

| # | Flaw in Previous Website | Solution in Redesigned Platform |
|---|--------------------------|---------------------------------|
| 1 | **Identical Fake Reviews**: Every product had identical placeholder text (`★★★★★ 1311 reviews`). | Unique, realistic ratings and verified review counts tailored to each product, alongside full ingredient lists and directions. |
| 2 | **Duplicated Testimonial Cards**: Customer quotes were duplicated twice back-to-back in the slider. | Distinct, authentic testimonials with verified buyer badges, ratings, and diverse Indian city locations. |
| 3 | **Inconsistent Branding & Contacts**: Mixed `.in`/`.com` domains, conflicting email addresses, and unexplained contact names. | Unified official contact info, direct phone lines (`+91 9716517463`), email (`secondsightfoundation@gmail.com`), and physical center address in New Delhi. |
| 4 | **Heavy Asset Bloat & Negative Margin CSS Hacks**: Multiple competing libraries (Bootstrap, Slick, Swiper, Mmenu, RemixIcon, IonRangeSlider) loaded at once with negative margin hacks (`margin-top: -50px !important`). | Clean, zero-bloat custom design system built with CSS variables, fluid responsive typography, and pure Vanilla JavaScript. |
| 5 | **Static / Broken E-Commerce Functions**: Cart popup was static or broken; currency selector did not calculate conversions. | Full client-side reactive store engine with slide-out cart, live shipping calculator, coupon validation, and local storage persistence. |
| 6 | **Uncategorized Products**: Teas, sprays, bottles, and skincare were all clumped in flat static lists. | Interactive category tabs (*Wellness Teas, Sprays & Aura Care, Skincare & Body, Nutrition & Combos, Mind & Lifestyle*), live instant search, and sorting. |
| 7 | **Missing Product Details**: Customers could not see ingredients, directions of use, or specific benefits. | Interactive Quick View modal with rich ingredient lists, botanical benefits, and direct add-to-bag controls. |

## 💻 Local Setup & Quick Start

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/RITESH-we/second-sight-foundation-demo.git
   cd second-sight-foundation-demo
   ```

2. **Open Directly:**
   * Double-click `index.html` in your file explorer to open it in any web browser.

3. **Or Run via Local Server:**
   ```bash
   python -m http.server 8000
   ```
   Visit `http://localhost:8000` in your browser.
